📋 Setup Instructions

To enable the full AI capabilities of Spectrum AI Pro Enhanced with Gemini Nano:

  1. Chrome Version Requirements
    Use Chrome 127 or higher. For best results, use Chrome Dev or Canary:
    • Chrome Dev
    • Chrome Canary
  2. Enable Chrome Flags
    Navigate to chrome://flags and enable these two flags:
    • #prompt-api-for-gemini-nano → Set to "Enabled"
    • #optimization-guide-on-device-model → Set to "Enabled BypassPerfRequirement"
  3. Restart Chrome
    Completely quit and restart Chrome after enabling the flags.
  4. First-Time Model Download
    The first time you use an AI feature, Gemini Nano (~1.5GB) will download automatically. This requires:
    • User interaction (clicking an AI button)
    • Good internet connection
    • 5-10 minutes depending on speed
⚠️ Note: The Prompt API with Gemini Nano requires specific hardware capabilities. If your device is incompatible, AI features won't work even with flags enabled.
