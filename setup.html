🚀 Quick Start

Get started with Spectrum AI Pro in just a few steps:

1

Enable Chrome AI Features

Make sure you have Chrome 127+ and enable the required flags:

  • Go to chrome://flags/#prompt-api-for-gemini-nano → Enable
  • Go to chrome://flags/#optimization-guide-on-device-model → Enable
  • Restart Chrome completely
2

Download AI Model

Get the on-device AI model for local processing:

  • Go to chrome://components
  • Find "Optimization Guide On Device Model"
  • Click "Check for update"
  • Wait for download to complete (may take a few minutes)
  • Restart Chrome once more
3

Start Using Spectrum AI

Right-click on any webpage and select "Open Spectrum AI" or use the keyboard shortcuts:

  • ⌘+⇧+A Run comprehensive audit
  • ⌘+⇧+S Start Scribe recording
  • ⌘+⇧+O Organize tabs with AI
