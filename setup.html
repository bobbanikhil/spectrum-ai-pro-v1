🎮 How to Use

Get started with these simple steps:

  1. Pin the Extension: Click the puzzle piece icon and pin Spectrum AI Pro for easy access
  2. Open Side Panel: Click the extension icon or use Ctrl+Shift+A to open the main interface
  3. Run Your First Audit: Navigate to any website and click "🚀 Run 12-Point Audit"
  4. Explore Features: Try tab organization, workflow recording, and history management
